قم بإنشاء تطبيق ويب متكامل (Progressive Web App - PWA) مخصص لعرض وتشغيل ملفات الدراسة باستخدام HTML و CSS و JavaScript فقط (بدون أي مكتبات أو أطر عمل).

يجب أن يعمل التطبيق كتطبيق حقيقي عند إضافته إلى الشاشة الرئيسية من خلال Safari (وضع ملء الشاشة، تجربة سلسة تشبه التطبيقات).

### المتطلبات الأساسية:
- تصميم متجاوب بالكامل (Mobile First) ومناسب للآيفون
- واجهة حديثة ونظيفة مع دعم الوضع الليلي والنهاري
- سرعة عالية في الأداء وتحميل سريع
- يعمل بدون إنترنت (Offline) باستخدام Service Worker

### ميزات الملفات:
- رفع وفتح الملفات:
  - PDF
  - صور
  - فيديو
- عارض PDF مدمج يدعم:
  - التكبير والتصغير
  - تظليل النص
  - إضافة ملاحظات
- مشغل فيديو يدعم:
  - تغيير سرعة التشغيل
  - حفظ آخر نقطة مشاهدة

### الميزات الذكية:
- البحث داخل الملفات (بحث نصي بسيط)
- إضافة الملفات إلى المفضلة
- تحديد الملفات كمكتملة
- إضافة ملاحظات لكل ملف
- تحويل النص إلى صوت (Text-to-Speech)

### أدوات الدراسة:
- مؤقت دراسة (Pomodoro Timer)
- مخطط دراسة يومي (باستخدام localStorage)
- تتبع التقدم (عدد الساعات، الملفات المكتملة)

### نظام المستخدم (محلي فقط):
- تسجيل دخول وإنشاء حساب باستخدام localStorage
- حفظ بيانات المستخدم محليًا

### ميزات PWA:
- ملف manifest.json يحتوي على الاسم والأيقونة والألوان
- Service Worker للتخزين المؤقت والعمل بدون إنترنت
- شاشة بداية (Splash Screen)
- قابل للإضافة إلى الشاشة الرئيسية على الآيفون

### تجربة المستخدم (UI/UX):
- تنقل داخل التطبيق بدون إعادة تحميل الصفحات
- شريط تنقل سفلي (الرئيسية - الملفات - المفضلة - الإعدادات)
- حركات وانتقالات سلسة
- تصميم مناسب للمس

### ميزات إضافية:
- رفع الملفات بالسحب والإفلات (Drag & Drop)
- إشعارات (Browser Notifications)
- دعم لغتين (العربية والإنجليزية)
- حفظ آخر ملف تم فتحه

### متطلبات الكود:
- تنظيم الملفات بشكل واضح:
  - index.html
  - style.css
  - app.js
  - service-worker.js
  - manifest.json
- كود نظيف ومفهوم مع تعليقات
- استخدام JavaScript الحديث (ES6+)
- بدون أي مكتبات خارجية

### النتيجة المطلوبة:
توفير كود كامل جاهز للعمل مع شرح طريقة التشغيل والرفع (مثل GitHub Pages).
